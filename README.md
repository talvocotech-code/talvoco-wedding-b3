# Talvoco UK wedding invitation template B3

Talvoco UK wedding invitation template B3 - demo with fictional names, dates and venues.

- Live demo: https://talvoco-wedding-b3.vercel.app/
- Built with Vite. Run locally: `npm install && npm run dev`; production build: `npm run build`
- Client content lives in `public/assets/js/config.js` (demo values: replace per customer)
- Made by [Talvoco](https://talvoco.com)
